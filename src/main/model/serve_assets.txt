# serve_assets.txt — the markdown viewer's render libraries, pinned.
#
# The requirements.txt of `yoga server`: serve_markdown.py fetches each artifact
# below into tmp/cache/serve_markdown/ on the first `yoga server start` (or `yoga server ensure-assets`),
# and src/PREREQUISITES.sh reports how many are present. Two upstreams — marked 9 and
# KaTeX 0.16.9 — the js/css plus the woff2 webfonts KaTeX needs to render maths.
#
# Format: one artifact per line, "<dest> <url>", dest relative to tmp/cache/serve_markdown/.
# The core js/css are REQUIRED (serve refuses to start without them); the fonts/ are
# progressive enhancement, fetched best-effort. To bump a version, edit the URLs here
# and `yoga clean --apply && yoga regen` (or delete tmp/cache/serve_markdown and re-serve).
