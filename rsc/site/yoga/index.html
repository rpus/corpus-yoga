§1

The practice

Your conversations with machines are a corpus — the only record of what you actually thought, asked, and were told. This repo treats that corpus with the rigour it deserves: every export validated against versioned schemas, every memory state deposited before its source is rewritten, every artifact keyed by durable identity rather than by whatever it happened to be called that day.

Two disciplines carry everything. Human-and-agent-amenable: each artifact serves both audiences — prose that machines can parse, data that people can read. Reproducible from the repo: no process is real if it lives only in a chat window or a terminal scrollback; the machine proposes in files, the human disposes in files, and a gate reports anything pending.

The corpus proposes its own vocabulary; the judgment stays yours. Every answer names the legal next moves — the interface is the documentation is the data.

§2

The routes rsc/cli/

One curated table is the whole surface — rendered as help in a terminal, as completion in a shell, as routes here. Each entry cites the calculus operations it performs, and the pre-commit tier holds every citation to the doctrine that defines it. These paths are not yet routed — today the terminal is the surface; the table is the same either way.

  • /yoga/run Every pipeline against its inputs; --plan prints the ordered steps that execute. ⟨atomise validate supersession accumulate project⟩
  • /yoga/calculus The corpus calculus — objects, operations, products, laws; extracted from working code, never designed ahead of it. ⟨the doctrine itself⟩
  • /yoga/index A book-style index over every conversation: headwords to durable turn anchors, locators that survive renumbering. ⟨project curate⟩
  • /yoga/memories Every distinct memory state, deposited before the source rewrites it — a diffable timeline of what the machine believed. ⟨accumulate normalise project L1 L4⟩
  • /yoga/supersede Do later exports supersede earlier ones? Computed per component; never assumed. ⟨supersession L3⟩
  • /yoga/agent Move an agent — session × memory — between machines, with every conflict loud. ⟨transport supersession merge L1 L6⟩
  • /yoga/machine Docker-style room manifests: desired state as committed data, observation strictly local. ⟨validate L2 L8⟩
§3

The laws rsc/CALCULUS.md

  • L1

    Idempotence. Every operation, re-run, is a no-op. There are no migrations, only normalisations — running one on a current corpus proves itself by silence.

  • L2

    Determinism split. Committed artifacts are machine-invariant; machine facts never enter them.

  • L3

    Licensed deletion. Nothing is deleted on assumption — only on a computed verdict or a deposit that stands in for it.

  • L5

    Presentation is never load-bearing. Names, numbers, and titles are dressing, re-derived at will from durable identity.

  • L6

    Conflicts are loud. Nothing overwrites divergent content silently; human judgment is summoned, not preempted.

  • L8

    Absence is a signal. Missing data is an informative skip; a crashed step surfaces. Nothing fabricates a value where the honest state is unknown.

Six of eight shown; the calculus names its enforcement — or the incident that taught it — beside each.

§4

The agents

An agent is two files: an append-only session and a folder of memory. That makes it portable — copy both and the agent resumes mid-thought on another machine, remembering the conversation that built the vehicle it arrived in. A forked agent is two agents thereafter: hone, not clone. 

$ yoga agent receive --from home-room --apply
receive ← home-room: a6f25723-….jsonl
  session: new
  memory/MEMORY.md: new
$ yoga agent receive --from home-room --apply
  session: identical — no-op
  memory/MEMORY.md: identical — no-op

Run it twice and the second run is silence — L1, observed. Divergence would have refused loudly instead — L6, ready.
